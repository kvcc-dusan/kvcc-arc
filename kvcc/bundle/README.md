# kvcc bundle

Single-file build of the kvcc design system for places with no npm: Claude artifacts, mini apps, prototypes. Generated by `node kvcc/scripts/build-bundle.mjs` into `kvcc/bundle/dist/`. Hand-written inputs are in `src/`.

## Files in `dist/`

| File | What |
|---|---|
| `kvcc.css` | Tokens (`foundation.css` plus `kvcc/theme.css`), base styles, scoped component CSS, bridges for motion. Includes a Google Fonts `@import`; drop it if you load the fonts with a `<link>`. |
| `kvcc.js` | Vanilla JS, no dependencies. Defines `window.kvcc`. |
| `kvcc-bundle.html` | Demo and markup reference with one example per component. |
| `template-app.html` | Full-page starter: app shell, stat cards, charts, table. |
| `design-system.html` | Reference page published as the Claude artifact. |

## Using it in an artifact

1. Inline `kvcc.css` in a `<style>` and `kvcc.js` in a `<script>` (end of body). Add the Google Fonts `<link>` for Geist and Inter (weights 400, 500).
2. Write markup with the class names from `kvcc-bundle.html`. Classes are `kv-<component>__<part>`, for example `kv-button__button kv-button__primary kv-button__md`.
3. Call `kvcc.setTheme(...)` and `kvcc.setAccent(...)` on load. Accents: neutral, violet, blue, green, amber, orange, coral, rose.

## `window.kvcc`

| Call | Does |
|---|---|
| `setTheme(theme)`, `setAccent(name)` | Sets `data-theme` and `data-accent` on `<html>`. |
| `toast({ title, description, duration })` | Shows a toast in a polite live region. |
| `openDialog(id)`, `closeDialog(id)` | Dialog markup: `[data-kv-dialog]` with overlay and content. Openers `[data-kv-open="id"]`, closers `[data-kv-close]`. Traps focus, Escape closes, focus returns. |
| `setProgress(el, value)` | Updates a `[role=progressbar]`. |
| `select(host, { label, options, value, placeholder, hint, onChange })` | Combobox-pattern select. |
| `table(host, { caption, columns, rows, selectable, sort, itemName, onSelectionChange })` | Sortable table with optional row selection. |
| `barChart(host, { data, label, period, unit })`, `sparkline(host, { values, label, headline, labels })` | SVG charts with scrub by pointer or arrow keys. |
| `dropdownMenu(host, { label, items, icon, onSelect })` | Menu button with roving focus, gliding highlight, typeahead. Items: `{ id, label, icon, destructive, disabled }` or `{ separator: true }`. |
| `popover(trigger, panelOrId, { side })` | Anchors any hidden panel to a trigger. Also wired by `[data-kv-popover="panel-id"]`. Escape and outside click close it and return focus. |
| `appShell(host, { brand, groups, activeId, title, onNavigate, actions, footer })` | Sidebar, top bar, content region. Returns `{ main, setActive, setTitle }`. |

Wired by attributes: tabs (`[data-kv-tabs]`), switch and checkbox (`[data-kv-toggle]`), tooltip (`[data-kv-tooltip="text"]`).

## Not covered

Line chart with axes, donut, command palette, date pickers, rich text. Build those to `kvcc/skill/kvcc-arc/references/rules.md` or use the React registry.
